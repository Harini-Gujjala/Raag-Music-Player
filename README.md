# 🎵 Raag Music Player

**Raag** is a responsive web-based music player built using **HTML, CSS, and JavaScript**. It provides a clean and interactive interface for discovering and playing songs through an external music API.

🔗 **Live Demo:** [Raag Music Player](https://harini-gujjala.github.io/Raag-Music-Player/)

---

## ✨ Features

* 🔍 **Search Songs** – Search for songs using the integrated music API.
* ▶️ **Music Playback** – Play and control songs directly from the browser.
* 📋 **Queue Management** – Manage the songs currently queued for playback.
* ❤️ **Liked Songs** – Save songs you like for quick access.
* 🎶 **Personal Playlists** – Create playlists and add songs to them.
* 🕘 **Recently Played** – Keep track of recently played songs.
* 🔊 **Volume Control** – Adjust the playback volume.
* 📱 **Responsive Design** – Designed to work across different screen sizes.
* 🌐 **Web App Support** – Includes a web app manifest and application icons.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Harini-Gujjala/Raag-Music-Player.git
```

### 2. Navigate to the project

```bash
cd Raag-Music-Player
```

### 3. Run the project

Since this is a front-end web application, you can open `index.html` directly in your browser.

For a better development experience, you can use **VS Code with Live Server** or another local development server.

---

## 🎮 How to Use

1. Open the **Raag Music Player**.
2. Search for a song using the search bar.
3. Select a song from the results.
4. Use the playback controls to play, pause, skip, or navigate through the song.
5. Add songs to your **Liked Songs** or **Playlists**.
6. Use **Queue**, **Shuffle**, and **Repeat** to customize playback.
7. Check **Recently Played** to revisit songs you've listened to.
